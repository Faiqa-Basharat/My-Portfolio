# Faiqa Basharat | Personal Portfolio

A modern, dark-themed personal portfolio showcasing my work in **UI/UX Design and Front-End Development**. Built from scratch using vanilla HTML, CSS, and JavaScript, with a focus on clean design, responsive layouts, and interactive user experiences.

## Portfolio Preview

![Portfolio Preview](https://github.com/Faiqa-Basharat/My-Portfolio/raw/main/assets/portfolio.png)

## About the Project

This portfolio serves as a central showcase of my design and development journey, featuring selected UI/UX case studies, front-end projects, technical skills, and professional experience.

Designed as a single-page website, it combines a minimal dark aesthetic with interactive components and smooth navigation to create an engaging browsing experience.

## Key Features

- **Floating Navigation:** Pill-style navigation with scroll-based active section highlighting.
- **Interactive Case Studies:** Project cards that open detailed case-study modals.
- **Experience Timeline:** Interactive timeline for exploring internship and professional experience.
- **Contact Form:** Opens a pre-filled email draft for convenient communication.
- **Custom Visual Design:** Dark theme featuring grain textures, radial gradients, and refined typography.
- **Responsive Layout:** Adaptable navigation, project cards, and content layouts across different screen sizes.
- **Smooth Interactions:** JavaScript-powered navigation, transitions, and interactive components.

## Getting Started

This project uses vanilla HTML, CSS, and JavaScript, so no frameworks or build tools are required.

### 1. Clone the Repository

```bash
git clone https://github.com/Faiqa-Basharat/My-Portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd "My Portfolio"
```

### 3. Run the Project

Open `index.html` directly in your browser, or use a local development server such as VS Code Live Server.
